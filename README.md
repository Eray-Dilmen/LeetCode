# LeetCode Solutions

A curated collection of my LeetCode problem solutions, explanations, and complexity analyses.

> **Note:** Problem titles in each folder are hyperlinked directly to the corresponding LeetCode problem page.

## Structure
Each problem folder contains:
- `solution.sql` / `solution.py`: Clean and optimized code.
- `README.md`: Problem summary, approach, and asymptotic complexity in English.
- `README.tr.md`: Personal study notes and explanations in Turkish.
